# WEEV-codon-analysis

This repository contains the data, analysis scripts, and results for the codon usage analysis of western equine encephalitis virus (WEEV).

## Repository Structure
- `data/`: Sequence data used for the analyses.
- `scripts/`: R and Python scripts for sequence extraction, codon usage indices (e.g., RSCU, ENc, CAI, COA), and statistical analyses.
- `results/`: Output tables and figures generated by the scripts.

## Software and Dependencies
Analyses were performed in R (version 4.6.1) and Python 3. 
Key R packages include: `tidyverse`, `seqinr`, `Biostrings`, `here`, `vegan`, and `patchwork`.
